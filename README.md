# AI News Digest Bot 🤖 → [**t.me/im_like_ai**](https://t.me/im_like_ai)

Python-бот, который превращает шум из 12 RSS-лент про ИИ в живой Telegram-канал:
отбирает по-настоящему важное через DeepSeek, пишет разборы «почему это важно»
и ведёт расписание — утренний топ-5, отборные новости днём и «Топ-5 недели».

**Канал, который работает на этом боте:** 👉 [**Что там у AI 👀**](https://t.me/im_like_ai)

```
🌅 09:00  «Главное за день» — топ-5 новостей за сутки
🔍 12:00 / 16:00 / 20:00  2–3 отборные новости с разбором и вопросом-хуком
🏆 вс 14:00  «Топ-5 недели» — якорный пост для пересылок
```

## Возможности

- **12 RSS-лент** (Habr, TechCrunch, WIRED, arXiv, блоги OpenAI/DeepMind/Google…)
- **Курирование через DeepSeek**: из потока заголовков выбираются 2–3 действительно
  важных события; дубли одного события на разных языках схлопываются
- **Пост без перехода на сайт**: русский заголовок + пересказ 2–4 предложения +
  вывод «почему это важно» + практический «как применить» для инструментов
- **Вовлечение**: вопрос-хук в каждом посте и кнопка «Переслать другу» (t.me/share)
- **Антишум**: дедуп по канонической ссылке и заголовку, per-source cap (arXiv
  не затопит ленту), лимиты скорости постинга, age-фильтр
- **Расписание на systemd-таймерах**: утренний дайджест, 3 дайджеста в день,
  недельный топ
- **Метрики** (`stats.py`): подписчики и просмотры в дневник `stats.json`,
  чтобы видеть, какие изменения работают

## Быстрый старт

```bash
git clone https://github.com/GitChyuk/ai-news-telegram-bot
cd ai-news-telegram-bot
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt

cp .env.example .env    # заполнить токен бота и канал
.venv/bin/python bot.py digest   # разовый прогон подборки
```

Создание бота и канала — через [@BotFather](https://t.me/BotFather):
боту нужен `Post Messages` в канале.

### Расписание (systemd user-units)

Юниты лежат в [`deploy/`](deploy/) — скопировать в `~/.config/systemd/user/`,
затем:

```bash
systemctl --user daemon-reload
systemctl --user enable --now ai-news-digest.timer ai-news-daily.timer ai-news-weekly.timer
loginctl enable-linger $USER   # чтобы таймеры жили после выхода
```

| Таймер | Когда | Что делает |
|---|---|---|
| `ai-news-daily.timer` | 09:00 | «Главное за день» (топ-5) + снимок метрик |
| `ai-news-digest.timer` | 12:00, 16:00, 20:00 | 2–3 отборные новости с разбором |
| `ai-news-weekly.timer` | вс 14:00 | «Топ-5 недели» |

## Метрики

```bash
.venv/bin/python stats.py snapshot   # снять замер (подписчики, просмотры)
.venv/bin/python stats.py report 7   # динамика за неделю
```

## Как устроено

```
RSS ×12 ──► дедуп (канон. ссылка + заголовок) ──► курирование (DeepSeek)
                                                      │
        ┌─────────────────────────────────────────────┘
        ▼
  describe() — заголовок, пересказ, takeaway, hook, howto
        ▼
  render() — HTML-пост с CTA ──► Telegram Bot API ──► канал
```

~650 строк Python, зависимости: `feedparser`, `requests`. Секреты — только
в `.env` (в репозиторий не попадает).
